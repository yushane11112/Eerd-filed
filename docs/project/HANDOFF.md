## 4. 每次换电脑前必须做什么

在当前电脑结束工作前，必须确保：

```bash
git status --short
git push
```

如果 `git status --short` 还有未提交文件，就需要先完成：

```bash
git add <changed-files>
git commit -m "<clear message>"
git push
```

原则：

- 稳定成果必须提交并推送。
- 半成品如果会影响另一台电脑接续，也要么提交到当前工作分支，要么明确记录在 `progress-dashboard.md` 的风险/下一步中。
- 不要依赖“我记得刚才做了什么”；所有连续性都要写进仓库。
