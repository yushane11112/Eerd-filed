# 小耳岛项目中枢

本目录是《小耳岛》真实城市模拟游戏的多会话协作中枢。

## 主目标

交付一款横屏、可全屏、可拖拽缩放的东方水乡城市模拟游戏。道路、家庭、就业、生产、仓储、物流、市场、财政和服务均由真实模拟状态驱动；普通材料在世界中随机掉落并可手动拾取，听完歌曲只结算稀缺材料。

## 协作规则

- `src/simulation/contracts.ts` 是公共协议唯一来源，由主会话维护。
- 并行任务、子会话产物和回流规则记录在 `parallel-production.md`。
- 子会话只修改任务清单中分配的目录，不覆盖其他会话改动。
- 模拟层不得引用 React 或 PixiJS；渲染层不得直接修改模拟状态。
- 每项任务必须包含实现、测试、变更清单和已知限制。
- 合并顺序：协议 → 模拟 → 世界 → 物流 → 渲染 → UI → 内容 → 验收。
- 建模、二维设色和动画分别验收：先完成统一体块与拆件，再进行材质设色和状态动画，禁止用平面补画掩盖模型比例问题。

## 当前里程碑

第一里程碑目标是完成可运行的垂直切片：

1. 等距地图上自由铺路和放置建筑。
2. 家庭迁入、就业、生产和搬运真实运行。
3. 居民与货物依据模拟状态动态显示。
4. 普通材料随机掉落并手动拾取。
5. 歌曲完成事件概率结算稀缺材料。
6. 支持全屏、拖拽、缩放、暂停和倍速。
