# 《小耳岛》28 类建筑美术审计与重画清单

版本：1.0  
任务：ART-AUDIT-01  
审计范围：28 类建筑、0–8 级成长、地块环境、动画拆件、建模输入  
结论等级：Fail，现有建筑资产不能作为最终资产，只能作为灰盒/节奏验证占位。

## 1. 审计结论

当前建筑方向没有达到“从原始荒地到繁华水乡城镇”的要求。核心问题不是单张图精细度不够，而是生产方法错了：把建筑当成孤立图标升级，会天然导致最高级仍像“草地上贴了几个亭子/船/房子”，而不是完整城市肌理。

必须整体重做，且按正式游戏资产流水线推进：

1. 先定城市规划与地块功能，再画建筑。
2. 先做体块、占地、入口、道路和人流验证，再做最终线稿与上色。
3. 每个建筑 0–8 级必须包含“主体、院落、道路、经营活动、人群密度、环境覆盖率”的同步成长。
4. 建筑不能只换屋顶或加装饰；1/3/5/7 级必须改变主体体量和轮廓，2/4/6/8 级必须增加功能环境与动态细节。
5. 8 级不能保留废墟观感，也不能留下大块无用途空草地。农业、盐场、园林可以有开放空间，但必须是有结构、有生产或游览用途的空间。

## 2. 现有资产硬失败项

| 问题 | 后果 | 判定 |
| --- | --- | --- |
| 高等级只局部替换建筑主体 | 玩家感觉不是城市升级，只是空地上贴了新房子 | Fail |
| 多数建筑终局趋同为亭子、船、桥、泛古风小楼 | 28 类建筑功能不可辨，城市失去文明运行感 | Fail |
| 缺少可动画拆件 | 无法做状态驱动施工、生产、营业和物流表现 | Fail |
| 地块边界、入口和道路关系不稳定 | 无法接入真实道路、寻路、服务半径和物流系统 | Fail |
| 0–8 级缺少统一成长语法 | 每级升级没有期待感，最高级不够“极致” | Fail |
| 美术依赖单张整图或平面贴图观感 | 无法支撑拖拽、缩放、遮挡、LOD 和动态引擎 | Fail |

## 3. 重画验收规则

### 3.1 功能辨识

隐藏建筑名称后，评审者必须在 3 秒内通过剪影和功能物件识别建筑用途。每栋建筑必须有：

- 1 个主识别体：例如龙窑、水轮、戏台口、盐池、船台。
- 2 个辅助识别物：例如晒架、货棚、药柜、粮囤、候船亭。
- 1 条专属运行动态：例如织机往复、水车转动、灯塔光束、戏台开锣。

不能把“飞檐、灯笼、船、小亭子、拱桥”当成通用繁华答案。

### 3.2 等级成长

| 等级 | 必须变化 | 禁止做法 |
| --- | --- | --- |
| L0 | 废墟/荒地，但要保留原功能线索 | 只放碎石，完全看不出未来用途 |
| L1 | 可使用的初级主体建筑 | 主体仍像废墟 |
| L2 | 增加入口、路面、小院或基础工具 | 只加光效或图标 |
| L3 | 主体体量升级，轮廓明显变化 | 只换颜色 |
| L4 | 增加生产/经营活动区和第一批居民活动 | 人物无状态空转 |
| L5 | 建筑群成型，附属建筑开始形成街区关系 | 全部建筑都变二层小楼 |
| L6 | 道路、摊位、仓储、庭院或服务设施补全 | 仍留大片无功能草地 |
| L7 | 地标级主体完成，但不破坏功能身份 | 泛化成亭台楼阁 |
| L8 | 满负荷营业/生产/生活，城市肌理闭合 | 保留废墟、空地、同质化装饰 |

### 3.3 地块覆盖率

- 商业/居住/公共建筑 L8：有效城市化覆盖率 80%–95%，包含建筑、道路、院落、摊位、绿化和人群活动。
- 作坊/仓储 L8：有效生产覆盖率 75%–90%，包含原料、加工、成品、装卸、消防/安全留白。
- 农业/盐业/园林 L8：有效功能覆盖率 85%–98%，开放空间必须是田、池、园路、水面、花圃或观演/游览区域。
- 港口/船坊 L8：水陆作业覆盖率 80%–95%，水面留白必须服务泊位、航道或下水流程。

## 4. 金标优先级

垂直切片先做 6 类金标资产，作为后续 28 类批量生产模板：

1. 柳岸民居 `main-homes`
2. 层层稻田 `windfield-rice`
3. 丰年粮仓 `main-granary`
4. 小满食肆 `main-eatery`
5. 青瓦瓷窑 `main-kiln`
6. 旧码头 `main-pier`

这六类必须优先完成概念、体块、L0/L1/L4/L8、美术、拆件、动画和引擎 prefab。没有金标，不允许批量开 252 个等级图。

## 5. 逐建筑重画清单

### 5.1 主镇岛：交通与入口

#### `main-pier` 旧码头（金标 P0）

- 功能身份：货运码头，不是观景亭。
- L0：断裂木桩、半塌栈桥、搁浅小货箱，仍能看出泊位方向。
- L1/L3/L5/L7：木栈桥 → 木石混合码头 → 多泊位货棚 → 石砌主埠与吊装架。
- L2/L4/L6/L8：系缆柱、货垛、搬运路线、分区货棚、排队船只和装卸工人逐级增加。
- L8 验收：至少 3 个泊位、2 条清晰人货流线、吊杆/旗绳/搬运队列独立动画。
- 禁止：把最高级做成一艘大船旁边一个亭子。

#### `main-ferry` 青石渡口（P1）

- 功能身份：客运渡口，强调候船、排队、上下船。
- L0：破损石阶、倒掉的渡牌、短木桩。
- L1/L3/L5/L7：简易石阶 → 候船棚 → 双向候船院 → 完整渡运节点。
- L2/L4/L6/L8：票牌、栏杆、排队绳、遮雨廊、灯笼和旅客流量逐级增加。
- L8 验收：客流与渡船靠离岸由模拟事件驱动。
- 禁止：和码头共用同一货运吊杆视觉。

#### `main-bridge` 听雨桥（P1）

- 功能身份：通行桥和桥头生活，不是园林装饰。
- L0：断桥墩、临时木板。
- L1/L3/L5/L7：木便桥 → 青石平桥 → 单拱桥 → 宽桥面石拱桥。
- L2/L4/L6/L8：桥栏、桥灯、桥头摊、避雨棚、行人密度增加。
- L8 验收：桥体必须保持主角，两岸街市辅助繁华。
- 禁止：用船或亭子替代桥的成长。

#### `main-gate` 小耳镇口（P1）

- 功能身份：城镇边界与主路入口。
- L0：残碑、半倒门柱、碎石路。
- L1/L3/L5/L7：木牌坊 → 石木镇门 → 双侧值守房 → 镇口广场门楼。
- L2/L4/L6/L8：界碑、路灯、公告牌、行商停驻、进出人流逐级增加。
- L8 验收：成为道路网络入口，不是孤立牌坊。
- 禁止：做成宫殿式城门或仙侠牌楼。

### 5.2 主镇岛：商业与生活

#### `main-inn` 临水客栈（P1）

- 功能身份：住宿与接待。
- L0：塌屋架、旧客牌、破行李箱。
- L1/L3/L5/L7：小客舍 → 二层临水楼 → 前厅后院 → 多进客栈院。
- L2/L4/L6/L8：客房窗、行李架、晾被、接待柜、住客进出逐级增加。
- L8 验收：可见“入住—休息—离店”循环。
- 禁止：和茶楼共用露台小楼剪影。

#### `main-teahouse` 半日茶楼（P1）

- 功能身份：饮茶、说书、临河休闲。
- L0：倒茶旗、破灶台、半塌露台。
- L1/L3/L5/L7：茶摊 → 开敞茶棚 → 二层茶楼 → 分层露台茶楼。
- L2/L4/L6/L8：茶桌、茶旗、茶灶、说书角、窗边坐客逐级增加。
- L8 验收：茶客坐席密度和添茶动作可读。
- 禁止：变成客栈或戏台。

#### `main-eatery` 小满食肆（金标 P0）

- 功能身份：厨房、饭点和街边烟火。
- L0：冷灶、破蒸笼、倒菜单牌。
- L1/L3/L5/L7：路边灶摊 → 小食铺 → 前店后厨 → 多灶口食肆与食棚。
- L2/L4/L6/L8：蒸笼、外摆桌、食客翻台、上菜路线和炊烟逐级增加。
- L8 验收：饭点出现高密度食客和厨师动作；非饭点降为备餐。
- 禁止：只加恒定烟雾当作营业。

#### `main-homes` 柳岸民居（金标 P0）

- 功能身份：连续居住街坊，是人口系统的视觉基础。
- L0：几处旧宅基、井台和残墙。
- L1/L3/L5/L7：单户小屋 → 三五户院落 → 巷弄住宅组团 → 连续水乡街坊。
- L2/L4/L6/L8：晾衣、灶烟、门牌、巷灯、儿童玩耍、邻里往来逐级增加。
- L8 验收：不能地标化；必须像人真正住在里面，街巷闭合且没有大空草地。
- 禁止：每户都变成小亭子或豪宅。

### 5.3 主镇岛：作坊与仓储

#### `main-weavery` 云锦布坊（P1）

- 功能身份：染织生产院。
- L0：破织机、空染缸、断晾架。
- L1/L3/L5/L7：小织棚 → 染缸院 → 长晾布坊 → 前店后坊大型染织院。
- L2/L4/L6/L8：布幅、排水沟、染工、织机往复、成品展示逐级增加。
- L8 验收：织、染、晒、售四个区域清楚。
- 禁止：只挂几条布当成完整布坊。

#### `main-carpentry` 榫卯木作（P1）

- 功能身份：木材加工与构件装配。
- L0：散木料、坏工作台。
- L1/L3/L5/L7：木棚 → 开敞木作间 → 木料院与装配棚 → 大型构件作坊。
- L2/L4/L6/L8：锯木、刨花、成品构件、抬梁路线和木屑堆逐级增加。
- L8 验收：可见原木进入、构件产出。
- 禁止：做成普通民居加木堆。

#### `main-kiln` 青瓦瓷窑（金标 P0）

- 功能身份：高温烧制产业。
- L0：坍塌窑口、碎瓦片、冷灰。
- L1/L3/L5/L7：小馒头窑 → 单龙窑 → 双窑制坯院 → 完整陶瓷生产院。
- L2/L4/L6/L8：泥坯架、柴垛、烟囱、冷却场、搬坯工人逐级增加。
- L8 验收：制坯、晾坯、入窑、出窑四阶段可在地块内读出。
- 禁止：只画一个漂亮烟囱房。

#### `main-granary` 丰年粮仓（金标 P0）

- 功能身份：储粮与装卸中心。
- L0：破粮囤、散落麻袋、塌仓脚。
- L1/L3/L5/L7：小粮囤 → 架空粮仓 → 多仓并列 → 大晒场与仓储组团。
- L2/L4/L6/L8：晒谷坪、推车、麻袋线、防鼠石、麻雀起落逐级增加。
- L8 验收：仓储容量、晒场面积、装卸路线必须清楚。
- 禁止：把粮仓做成普通二层楼。

#### `main-pharmacy` 草木药铺（P1）

- 功能身份：前铺后院的药材处理。
- L0：倒药柜、散药筛。
- L1/L3/L5/L7：小药铺 → 药柜门面 → 晒药后院 → 前诊后制完整药铺。
- L2/L4/L6/L8：药屉、药碾、草药束、翻晒架、称量动作逐级增加。
- L8 验收：诊、称、碾、晒四类动作至少两类同时可见。
- 禁止：变成茶楼或杂货铺。

### 5.4 主镇岛：公共与景观

#### `main-academy` 溪山书院（P1）

- 功能身份：教育与藏书。
- L0：残碑、破书案、半堵院墙。
- L1/L3/L5/L7：小书斋 → 讲堂 → 书院院落 → 多进书院与藏书楼。
- L2/L4/L6/L8：书案、月门、碑刻、晨读队列、先生巡堂逐级增加。
- L8 验收：气质安静，不靠烟火摊位凑繁华。
- 禁止：宫殿化。

#### `main-theatre` 水上戏台（P1）

- 功能身份：演出与聚集。
- L0：破台基、旧鼓架。
- L1/L3/L5/L7：小戏棚 → 水边戏台 → 后台厢房 → 完整戏台院与观演广场。
- L2/L4/L6/L8：帷幕、鼓架、观众席、演员入场、观众聚散逐级增加。
- L8 验收：定时演出，非演出时有维护/排练状态。
- 禁止：永久热闹但无事件驱动。

#### `main-garden` 临水花园（P1）

- 功能身份：游览、休憩、生态景观。
- L0：荒芜池塘、断石径。
- L1/L3/L5/L7：小花圃 → 荷池与石径 → 曲水游廊 → 多层水院园林。
- L2/L4/L6/L8：花窗、叠石、曲桥、游人、季节植物逐级增加。
- L8 验收：开放空间必须被水、路、花圃和游人组织起来。
- 禁止：大片空草地。

### 5.5 风禾岛：农业生产

## 6. 动画与拆件要求

每个建筑至少拆成以下层：

1. `base`：地基、地块、道路、田埂、水岸。
2. `body_back`：后景主体，参与遮挡。
3. `body_front`：前景主体，参与人物遮挡。
4. `props_static`：工具、货物、家具、植物。
5. `props_animated`：水轮、旗帜、布幅、灯、吊杆、炉火等。
6. `workers`：建筑专属工作位人物。
7. `vfx`：烟、蒸汽、水花、灯光、落叶、尘土。
8. `ui_anchor`：选择框、提示、缺货/停工指示位置。

动画不得无条件播放。每个动作必须绑定到模拟状态：

- `constructing`：脚手架、落瓦、木工、尘土。
- `working`：生产/营业动作。
- `waiting_for_input`：缺原料，人物停顿或清扫。
- `no_workers`：机器停止、人少、摊位半闭。
- `storage_full`：货物堆高、搬运停止。
- `closed`：灯灭、门半掩、活动降级。

## 7. 建模输入要求

建模不是“加一个 3D 感滤镜”。每个建筑进入模型阶段前必须交付：

- 等距三视体块图：正等距、背等距、顶视 footprint。
- 0/1/3/5/7 主体体量差异图。
- 2/4/6/8 院落与环境增量图。
- 入口、道路、物流点、居民活动点、选择框和遮挡层。
- 可动画部件 pivots：门、旗、布、轮、吊杆、灯、烟源、水源。
- LOD 切换方案：近景、中景、远景至少 3 档。

没有这些输入，禁止直接产出最终 PNG 或 prefab。
