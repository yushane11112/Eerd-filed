# 《小耳岛》美术全阶段生产计划

## 1. 美术最终目标

美术生产必须贯穿完整商业开发生命周期，不能只做首批金标建筑。

最终目标：

- 统一年代：架空明清江南水乡，前工业时代。
- 统一风格：东方水乡、白墙黑瓦、工笔设色、细节密集、温润低饱和。
- 统一系统：建筑、人物、道路、水岸、船、货物、摊位、灯火、环境都服务城市模拟。
- 统一质量：无 AI 感、无贴图感、无建筑雷同、无无意义空地、无静态死图。
- 统一动效：关键视觉状态由城市系统驱动。

## 2. 全阶段美术路线

| 阶段 | 目标 | 产出 | 验收 |
| --- | --- | --- | --- |
| ART-P0 美术方向冻结 | 建立全项目美术基准 | 世界视觉圣经、年代白/黑名单、材料、色板、线条、透视、人物比例、城市密度、禁用元素 | 任意新资产都能按规范判断是否合格 |
| ART-P1 灰盒视觉与功能辨识 | 系统灰盒阶段保证功能可读 | 地形、道路、水岸、桥梁、住宅、市场、仓库、生产、服务、行政、人物点、物流单位、状态符号 | 隐藏建筑名称后仍能判断功能；灰盒不得冒充最终资产 |
| ART-P2 概念设计与建筑谱系 | 建立完整建筑视觉谱系 | 住宅、商业、生产、服务、行政、街区谱系概念；每类含轮廓、占地、入口、动效挂点、低/高繁荣差异 | 不同建筑必须靠轮廓、结构、活动和附属物区分 |
| ART-P3 金标建筑与金标街区 | 做出最终质量垂直切片 | 民居、市场、粮仓、稻田、木作坊、码头；水乡商业街、码头仓区 | 证明最终城市可达到商业级视觉方向 |
| ART-P4 角色与人口视觉体系 | 区分外来人口、居民和职业角色 | 外来人口、正式居民、农人、工匠、商贩、挑夫、推车夫、船夫、巡丁、医师、学童、书生、消防役、官吏 | 入住前后、职业与阶层差异在远景可识别 |
| ART-P5 建筑状态与动画资产 | 关键建筑状态都有反馈 | 正常、缺工、缺货、仓满、停摆、施工、升级、火灾、疾病、低/高繁荣；炊烟、水车、窑火、织机、装卸、摊贩、灯笼 | 动画必须由模拟状态触发，不用统一光点/烟雾糊弄 |
| ART-P6 环境、地形与城市密度 | 让城市成为完整水乡空间 | 地形、农田、水岸、河道、池塘、荷塘、石岸、土岸、柳树、竹林、花圃、园林、小广场、长廊、灯会/庙会装饰 | 城市升级是空间升级，不是局部建筑升级 |
| ART-P7 UI 视觉与信息图层 | 管理复杂城市且不遮挡地图 | 状态栏、建造菜单、建筑详情、人口、财政、服务图层、风险图层、顾问、暂停/倍速/全屏、引导、图标 | 信息层级清晰，风格统一，玩家能快速诊断城市问题 |
| ART-P8 Alpha 内容量产 | 扩展到可玩内容规模 | 40–60 类建筑视觉方案、核心状态资产、街区资产、角色动画、环境资产、UI 全套、manifest 接入 | Alpha 能从村落成长到商贸镇，主要建筑不再是灰盒 |
| ART-P9 Beta 美术完整化 | 达到商业测试丰富度 | 80+ 建筑/街区方向、高级商业区、官署区、书院区、庙会区、码头贸易区、园林住宅区、夜市灯火、灾害表现、全量 UI | 从荒村到盛世水都变化明显，风格不漂移 |
| ART-P10 RC 美术冻结 | 上线前最终审计 | 全资产清单、缺失清单、占位替换清单、风格审计、年代审计、功能盲测、动画审计、性能审计、截图验收集 | 无核心灰盒残留，无错时代、明显 AI 感、同质化或不合理空地 |
| ART-P11 上线后美术运营 | 建立持续扩展能力 | 新建筑、新街区、节日、新地图、装饰、热更新和资产回归审计规范 | 新增内容不破坏统一年代和城市模拟 |

## 4. 美术质量门禁

每个建筑或街区必须通过：

- A0 年代一致。
- A1 功能清晰。
- A2 轮廓独特。
- A3 占地合理。
- A4 入口明确。
- A5 状态完整。
- A6 动画可绑定。
- A7 与周边街区融合。
- A8 性能预算合格。
- A9 盲测通过。
- A10 最终截图通过。

失败规则：

- 年代不一致：退回概念。
- 功能无法辨认：退回概念。
- 与其他建筑雷同：退回体块。
- 高级阶段不繁华：退回街区设计。
- 动画无法由状态驱动：退回动画方案。
- 性能超预算：退回拆件或特效。
