# 《小耳岛》可扩展建筑与街区体系

## 1. 原则

建筑类别不再限制为 28 类。建筑数量由城市模拟系统需要决定，但必须符合统一年代设定，并服务真实城市运行。

建筑扩展原则：

- 功能优先：每类建筑必须承担人口、生产、物流、市场、服务、财政、文化或风险治理功能。
- 年代统一：必须符合架空明清江南水乡。
- 可观察：建筑状态、缺口和繁荣程度必须能在地图上看见。
- 可扩展：先灰盒验证系统，再金标样板，再批量生产。
- 街区优先：高级城市繁荣主要来自街区形成，不只靠单栋建筑升级。

## 3. 建筑类别

### 住宅

- 草棚、茅舍、木屋、普通民居、小院住宅、商住院落、富户宅院、士绅宅第、园林宅院、河岸豪宅。
- 承载家庭、税收、需求、满意度、人口阶层和迁入/迁出。

### 道路与交通

- 土路、石板路、青石主街、木桥、石桥、拱桥、渡口、小码头、货运码头、运河埠头。
- 影响通勤、物流、服务覆盖、拥堵和城市形态。

### 农业与资源

- 稻田、菜圃、果园、桑园、茶园、药圃、竹林、渔场、盐田、伐木场、采石场、黏土坑。
- 提供基础资源和早期就业。

### 手工业

- 木作坊、砖瓦窑、陶瓷窑、布坊、染坊、纸坊、油坊、酿造坊、药坊、造船坊、食品作坊。
- 连接原料、工人、仓储、市场和高级商品。

### 仓储与商业

- 小仓库、大仓、粮仓、货栈、集市、米铺、鱼市、布市、茶铺、药铺、商行、客栈、酒楼、茶楼、钱庄、当铺、绸缎庄、香料铺、古玩铺。
- 支撑库存、市场消费、税收和商业繁荣。

### 公共服务

- 水井、水亭、医馆、巡防所、消防棚、学塾、书院、戏台、庙宇、祠堂。
- 影响住宅升级、满意度、风险和城市吸引力。

### 行政与礼制

- 牌坊、镇口、鼓楼、县衙、文庙、城门、城墙、议事厅、漕运署、税关、驿站。
- 支撑财政、治理、秩序、运输和文明阶段。

### 景观与文化

- 临水花园、园林、水榭、湖心亭、牌楼街、夜市、灯会广场、祈福台、河岸长廊、柳岸步道、荷塘、曲桥。
- 提升环境质量、文化需求和高级街区吸引力。

### 街区型建筑

- 商业街、夜市长街、茶楼街、食肆街、绸缎街、手工业坊区、水上集市、河岸商街、码头仓区、官署街、书院街、庙会街、园林住宅区。
- 解决后期城市空、散、同质化的问题，是盛世水都的核心表现。

## 4. 繁荣表现机制

城市繁荣提升时必须整体改变空间：

- 道路两侧增加摊位、灯笼、招幡、石灯、花圃。
- 住宅周边增加院墙、水缸、柴堆、晾衣、炊烟、孩童活动。
- 市场周边增加货担、摊棚、排队、人群和交易动作。
- 码头周边增加货箱、船只、搬运工、货栈和装卸路线。
- 高级街区出现牌楼、长廊、园林、水榭、灯火和职业人群。
- 暮色阶段从零星灯火逐步发展为夜市、灯会和河岸灯火。

## 5. 建筑准入标准

新增建筑必须具备：

- 所属城市阶段。
- 所属功能类别。
- 占地尺寸。
- 道路或水路连接点。
- 岗位、库存、服务或财政作用。
- 至少一种可观察状态。
- 年代一致性依据。
- 与已有建筑的差异化识别点。
