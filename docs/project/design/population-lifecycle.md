# 《小耳岛》人口生命周期设计

## 1. 原则

人口不能只是城市数字。外来人口在入住前后必须有身份、行为、视觉和系统影响差异。

核心生命周期：

`抵达 → 找房/找工 → 临时停留 → 正式入住 → 稳定生活 → 离城`

## 2. 外来人口

来源：

- 城门、渡口、码头、驿站、官道入口。

视觉：

- 包袱、扁担、推车、拖家带口、牵孩子、扶老人。
- 在城门、码头、客栈、告示牌附近停留和张望。

系统属性：

- 未登记人口。
- 不缴税。
- 无正式住宅。
- 无稳定工作。
- 可消耗少量临时食物或客栈容量。
- 有等待时限和离城风险。

## 3. 寻找落脚点

外来人口根据城市条件决定是否入住：

- 空住宅数量。
- 住宅道路连接。
- 食物供应。
- 水源覆盖。
- 可达工作岗位。
- 税率。
- 治安、疾病、火灾风险。
- 城市声望和近期人口流失情况。

行为：

- 查看空房。
- 靠近市场、工坊或客栈。
- 条件不足时等待。
- 长期失败则离开城市。

## 4. 临时停留

地点：

- 客栈、驿站、临时棚区、城门外空地、码头候船区。

影响：

- 增加城市热闹度。
- 带来少量消费。
- 可形成临时劳动力。
- 长期滞留会增加治安、疾病和满意度压力。

## 5. 正式入住

入住后变化：

- 分配住宅。
- 生成家庭成员结构。
- 成为正式居民。
- 纳入人口统计。
- 可以就业、消费、纳税。
- 产生完整生活需求。
- 参与住宅升级/降级和城市满意度计算。

视觉变化：

- 卸下包袱并进入住宅。
- 门口出现水缸、柴堆、晾衣、灯笼、炊烟等生活物件。
- 次日开始通勤、购物、取水、求医、上学或娱乐。

## 6. 稳定生活

正式居民行为：

- 上班、购物、取水、看病、参加娱乐、送孩子上学、纳税、夜间回家。

系统影响：

- 提供劳动力。
- 增加税收。
- 增加市场需求。
- 增加服务压力。
- 推动住宅升级或因需求不足而降级。

## 7. 离城

触发原因：

- 长期无食物。
- 长期无工作。
- 税负过高。
- 疾病严重。
- 治安恶化。
- 住房等级下降。
- 服务覆盖不足。
- 财政崩溃导致服务停摆。

表现：

- 重新背起包袱。
- 从住宅走向城门、码头或驿站。
- 住宅灯火熄灭，进入空置或破败状态。
- 城市人口、税收和劳动力下降。

## 8. UI 与验收

人口反馈必须显示：

- 今日抵达人数。
- 正在找房人数。
- 临时停留人数。
- 成功入住人数。
- 离开人数。
- 主要阻碍原因。

验收场景：

- 有空房、有食物、有岗位：外来家庭抵达并入住。
- 有空房但无岗位：等待后离开。
- 有岗位但无住宅：进入客栈或临时停留，长期无房后离开。
- 食物不足：迁入意愿下降。
- 税率过高：外来人口减少，居民可能流失。
- 新家庭入住后住宅出现生活细节，并开始通勤和消费。
