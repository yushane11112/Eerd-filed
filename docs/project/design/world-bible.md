# 《小耳岛》世界观与年代设定

## 1. 核心设定

《小耳岛》采用架空明清江南水乡文明设定。它不是历史复刻，但所有建筑、交通、服饰、产业、工具和城市治理方式必须服从同一前工业时代逻辑。

关键词：

- 架空江南水乡。
- 明清之间的传统农业商业社会。
- 白墙黑瓦、木构、石桥、青石路、运河、水岸、码头、街市。
- 人力、畜力、水运为核心交通。
- 县镇治理、街市商业、作坊生产、宗族礼制、书院文化。

## 2. 允许元素

### 建筑材料

- 木、竹、砖、瓦、石、夯土、灰墙、布幔、纸窗。
- 青瓦、黑瓦、灰瓦、木梁、石阶、青石板。

### 交通与物流

- 步行。
- 挑担。
- 手推车。
- 牛车。
- 小船。
- 驳船。
- 渡口。
- 运河码头。

### 城市设施

- 土路、石板路、青石主街。
- 木桥、石桥、拱桥。
- 水井、水亭。
- 仓库、粮仓、货栈。
- 市集、店铺、茶楼、酒楼、客栈。
- 县衙、税署、驿站、漕运署、鼓楼、城门、城墙。

### 视觉细节

- 灯笼、招幡、布旗、竹架、木桶、水缸、货担、竹筐、木箱。
- 炊烟、水车、窑火、织机、船篷、橹桨、岸边柳树。

## 3. 禁止元素

- 现代电力、电线、电灯杆、霓虹灯。
- 汽车、摩托、铁路、火车、现代货车。
- 蒸汽机械、机械吊臂、现代港口机械。
- 玻璃幕墙、钢筋混凝土高楼、现代公寓。
- 民国洋楼、欧式教堂、现代学校教学楼。
- 现代医院、现代警察局、消防车站。
- 未来机械、科幻设备、蒸汽朋克装置。

## 4. 风格原则

- 统一东方水乡，不做跨时代大杂烩。
- 建筑越高级，细节越密、街区越繁荣，但技术水平不跨时代。
- 繁荣表现来自人流、商业、灯火、船运、园林、礼制、行政和街巷密度，不来自现代化设备。
- 任何新增建筑必须先能在本设定中找到时代依据。

## 5. 年代一致性审计

新增资产必须回答：

1. 它的功能是否符合前工业水乡城市？
2. 它的材料和结构是否合理？
3. 它的交通、生产或服务方式是否依赖现代技术？
4. 它的服饰、道具、招牌是否跨时代？
5. 它是否能通过远景轮廓识别功能？

任一问题失败，资产退回概念阶段。
