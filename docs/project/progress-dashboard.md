# 《小耳岛》项目进度仪表盘

更新时间：2026-06-27

## 1. 当前阶段

当前阶段：P0 商业定位与项目中枢重构。

当前判断：

- 项目已有早期城市模拟、Pixi 渲染骨架、资产校验器、若干金标 manifest 样例和长稳测试。
- 但旧文档和部分实现仍混有岛屿、听歌材料、固定 28 建筑等旧方向。
- 本轮重点是把完整上线商业级目标、美术全阶段生产线和自动执行机制落到项目中枢。

## 3. 当前最大风险

- 旧方向残留：部分文档和代码仍围绕听歌材料、岛屿和固定建筑数量。
- 美术产能风险：商业级美术需要专业二维/三维/动画参与，工程只能先建立规范、灰盒、manifest 和金标样板。
- 模拟闭环风险：人口、就业、服务、财政、风险之间还没有完全形成长期自洽闭环。
- 视觉密度风险：后期繁荣必须依赖街区系统，否则容易回到“局部建筑升级 + 大片空地”。

## 4. 下一轮默认任务

1. 将代码主循环逐步从旧掉落/音乐入口降级为非主线。
2. 落地外来人口状态机与住宅入住状态。
3. 建立城市吸引力评分。
4. 重构建筑分类数据，支持可扩展时代一致建筑体系。
5. 补充金标码头 L0–L8 缺级或转入新金标街区样板。

## 5. 每轮更新要求

每轮完成后必须更新：

- 本仪表盘的阶段、完成度、风险和下一轮任务。
- `task-board.md` 的任务状态。
- `integration-log.md` 的集成记录。
- `artifact-index.md` 的真实文件产出。
- `qa.md` 的测试结果或缺口。
