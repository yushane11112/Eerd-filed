# 《小耳岛》整体镇貌美术重构规格

## 目标

把当前“固定空地底图＋独立建筑贴图”改造成同一座岛从荒岛逐步发展为极盛江南城镇的连续视觉成长。最高阶段必须消除不合理空草地，并让道路、河岸、背景民居、商业、作坊、公共空间、绿化和居民活动共同形成完整城镇。

## 五阶段完整镇貌

1. **荒岛遗址**：约 80% 为自然地貌和废墟，只保留残路、断桥和旧地基。
2. **初建聚落**：约 35% 建成覆盖；出现连续土路、小型民居、修复码头和生活院落。
3. **烟火村镇**：约 58% 建成覆盖；石路成网，河岸连续，出现商铺街、作坊区、集市和公共设施。
4. **江南水乡**：约 75% 建成覆盖；两岸建筑连续，街巷、桥梁、园林、码头和背景民居完整连接。
5. **极盛城镇**：约 88% 建成覆盖；不保留大块无用途空草地，形成高密度但可读的繁华水乡，拥有主街、次街、河岸商业、作坊后院、公共广场、园林、船运、人群和暮色灯火。

五张图必须保持完全相同的岛屿轮廓、河道、桥位、视角、光源和关键地标坐标，可以直接交叉淡化切换。

## 建筑类型约束

- 港口类：栈桥、泊位、货运、渔船和仓棚；不得发展成通用楼阁群。
- 桥梁类：桥体、桥亭、两岸桥头街市；不得出现独立大院。
- 餐旅商业：茶楼、客栈、食肆分别强调茶席、客房、厨房与餐台。
- 生产作坊：布坊、木作、瓷窑分别以染晒、木构、窑炉为主体。
- 公共设施：粮仓、药铺、书院、戏台保持仓储、药材、教学、演出功能轮廓。
- 居住与园林：民居形成连续街区；花园以水体、花木、廊桥为主体。
- 农业景观：稻田、果园、茶园、药圃、盐场最高级仍以大面积生产地貌为主。
- 船仅允许出现在港口、渡口、临河商业和船坊附近，不作为所有建筑的通用繁华符号。

## 渲染架构

- `TownscapeLayer` 根据全岛总等级选择五张完整镇貌图并交叉淡化。
- `LandmarkLayer` 仅绘制当前选中建筑及需要交互的功能建筑，不再同时把 28 张大型建筑贴满主岛。
- `ActivityLayer` 绘制居民、货运、摊位、灯火、水车、烟雾和船流动画，并按镇貌阶段提高密度。
- 建筑等级 0–8 映射到镇貌阶段 `[0,1,1,2,2,3,3,4,4]`；全岛阶段由全部建设点总等级决定，不被单座建筑瞬间拉满。
- 主题岛拥有各自的农业、山林、海工整体阶段图，不使用主镇楼阁资产替代。

## 验收标准

- 五张镇貌以相同尺寸叠放时，岛岸和河道偏差不超过 6 像素。
- 极盛主镇的有效建设覆盖率不低于 85%，无面积超过画面 3% 的无功能空地。
- 28 类建筑最高级通过轮廓辨识测试：隐藏名称后仍能依据主要功能元素区分。
- 农田、果园、茶园、药圃、盐场、桥梁、码头和灯塔不得被通用亭阁替代。
- 浏览器中从阶段 0 到阶段 4 切换时，城镇密度、道路和人流必须逐级增加，不出现倒退。
- 最终视觉需与关键帧逐项对比，通过整体密度、功能辨识、色彩、透视、层级和动效六项检查。
